# Atlas Context Tracker

This project tracks the usage and development of the Atlas skill/system itself, creating an intentional "Atlas tracking Atlas" scenario for self-validation and improvement.

## Purpose
Local-first project context tracking system that enables agents and humans to:
- Track live project context and ruleset evolution
- Maintain human-readable status reporting and to-do lists
- Establish foundation for multi-project tracking and kanban views
- Apply fact-checking and mathematical standards to self-improvement processes

## Core Concepts

### Inception by Design
While tracking Atlas with Atlas creates an inherent self-referential situation, this approach is intentional:
- **Dogfooding**: The system validates itself through actual usage
- **Self-observation**: Enables fact-based analysis of effectiveness
- **Continuous improvement**: Improvements grounded in real usage data
- **Accountability**: Creates transparent audit trail of evolution

### Local-First Principles
All tracking data lives within the project directory:
- **ATLAS.md**: Living ruleset and primary context tracker
- **evidence/**: Verifiable proof supporting claims and measurements
- **files/**: Reusable tools and templates for tracking
- **docs/**: Design specifications and documentation
- **src/tests/**: Source code and tests (if applicable)

### Tracking Workflow
1. Read ATLAS.md to understand current context
2. Work session: perform tracking activities
3. Update ATLAS.md: modify Status, Where I left off, Next Steps
4. Add evidence: place verifiable results in evidence/ directory
5. Apply fact checks: validate claims with evidence and reasoning
6. Plan next session: update Next Steps with prioritized actions

## Getting Started
Simply read the ATLAS.md file to understand the current state and tracking approach. The project is designed to be usable immediately by reading this single source of truth.

## Evolution
This project will evolve as we learn what works best for context tracking. The ATLAS.md file serves as both the tracker and the evolving ruleset for how we track - demonstrating the power of a living document that improves through use.
